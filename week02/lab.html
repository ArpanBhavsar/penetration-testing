3.1 Identify the ISP and SaaS problems

In scope.md, add a “Validation notes” section that explains why 203.0.113.200 and help.example must not be scanned yet.

Solution

203.0.113.200 falls in Coast ISP’s 203.0.113.128/25. Acme’s customer relationship is not ownership. help.example is a multi-tenant SaaS platform; Acme’s request alone is not vendor authorization. Both stay blocked until written third-party permission exists.

3.2 Build and run scope_guard.py

Implement the checker using the Python standard-library ipaddress module. Run it with --demo and save the output.

Reference implementation
#!/usr/bin/env python3
"""scope_guard.py — Week 2 helper for Penetration Testing (Focus College).

Refuse to proceed when a proposed target is outside the approved CIDR ranges
or appears on the exclusion list. Reuse this before Nmap in Week 3.

Usage:
  python3 scope_guard.py targets.txt
  python3 scope_guard.py --demo

The targets file contains one IPv4 address or host label per line.
Lines starting with # are comments.
"""
from __future__ import annotations

import argparse
import ipaddress
import sys
from pathlib import Path

# Acme Project Phase 1 approved ranges (lab + documentation examples)
IN_SCOPE = [
    ipaddress.ip_network("192.168.56.0/24"),  # course host-only lab
    ipaddress.ip_network("203.0.113.0/25"),   # Acme public half (docs range)
]

# Always refuse these even if they fall inside a wide CIDR
EXCLUSIONS = {
    ipaddress.ip_address("192.168.56.1"),     # VirtualBox host gateway (your laptop)
    ipaddress.ip_address("203.0.113.1"),      # reserved example gateway
}

# Labels that are never in scope for Phase 1 without a change order
BLOCKED_LABELS = {
    "help.example",          # SaaS help desk — vendor permission required
    "college.lms.example",   # college systems
}


def classify(token: str) -> tuple[str, str]:
    token = token.strip()
    if not token or token.startswith("#"):
        return "skip", "comment or empty"
    lower = token.lower()
    if lower in BLOCKED_LABELS:
        return "BLOCK", f"label '{token}' is excluded (third-party or college)"
    try:
        ip = ipaddress.ip_address(token)
    except ValueError:
        return "BLOCK", f"'{token}' is not a bare IPv4 address; resolve and re-check"
    if ip in EXCLUSIONS:
        return "BLOCK", f"{ip} is on the exclusion list"
    for net in IN_SCOPE:
        if ip in net:
            return "ALLOW", f"{ip} is inside {net}"
    return "BLOCK", f"{ip} is outside every approved CIDR"


def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(description="Check targets against Acme Phase 1 scope")
    p.add_argument("targets", nargs="?", help="Path to targets file")
    p.add_argument("--demo", action="store_true", help="Run built-in demonstration targets")
    args = p.parse_args(argv)

    if args.demo:
        lines = [
            "# demo targets for Week 2 lab",
            "192.168.56.101",
            "192.168.56.102",
            "192.168.56.1",
            "203.0.113.10",
            "203.0.113.200",
            "help.example",
            "8.8.8.8",
        ]
    else:
        if not args.targets:
            p.error("provide a targets file or --demo")
        lines = Path(args.targets).read_text(encoding="utf-8").splitlines()

    allowed = blocked = 0
    print("scope_guard.py — Acme Project Phase 1")
    print("Approved:", ", ".join(str(n) for n in IN_SCOPE))
    print("-" * 60)
    for line in lines:
        status, reason = classify(line)
        if status == "skip":
            continue
        mark = "✓" if status == "ALLOW" else "✗"
        print(f"{mark} {status:5}  {line.strip():20}  {reason}")
        if status == "ALLOW":
            allowed += 1
        else:
            blocked += 1
    print("-" * 60)
    print(f"Summary: {allowed} allowed, {blocked} blocked")
    return 1 if blocked else 0


if __name__ == "__main__":
    sys.exit(main())

Part 5 — Authorization & contracts

⏱ 20 min
Goal: Complete an authorization letter and review a flawed SOW/NDA excerpt.

5.1 Authorization letter

Write authorization.md with signer authority, named testers (or Annex A), exact scope, dates/times with zone, source networks, prohibitions, emergency contacts and a signature line.

Model letters follow the lecture sample: CIO Jordan Lee as signer; Annex A for student names; hosts 192.168.56.101/102 and 203.0.113.10 only; window 9–16 Oct 2026, 18:00–21:00 PT; SE/physical/DoS prohibited; phone contacts; signed and dated.

5.2 Find five problems in this excerpt

SOW excerpt: "Tester will assess Acme security as needed. NDA optional if everyone trusts each other.
Payment due someday. Social engineering included implicitly. Deliverable: vibes."
  1. Scope (“as needed”) is not exact.
  2. NDA is not optional for a real engagement with sensitive findings.
  3. Payment/acceptance terms are missing.
  4. Social engineering cannot be “implicit.”
  5. “Vibes” is not an acceptance criterion; name the report deliverable.
