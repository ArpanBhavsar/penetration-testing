Presentation controls

Use ← / → or Page Up / Page Down (or Space) to navigate. Home / End moves to the first / last slide. You can also link to a slide with #number at the end of the address.

M opens sections. O opens the overview. R toggles the all-slides reading view. F toggles fullscreen. Escape closes navigation.

Interactive diagrams respond to clicks: look for buttons, numbered markers, and shapes with a highlight when you hover. Activity answers are hidden behind “Reveal worked solution”.

This file works offline. Reference links need Internet access. Use Ctrl/Cmd + P to print the complete reading material: diagrams print with every panel expanded, so you get the full text.
