Refresh Acme’s passive dossier from simulated artifacts, gate targets with scope_guard, discover live hosts, port/service-scan with Nmap, run light NSE, and write five report-ready findings for Assignment 1.

Before you start

  • Bring your Week 2 Phase 1 scope / RoE package (or the class baseline: 192.168.56.0/24 excluding .1; window 18:00–21:00 PT; no DoS / SE / physical).
  • Create mkdir -p ~/acme-phase2a && cd ~/acme-phase2a.
  • Get the zip: download week3-lab-assets-student.zip and unzip it next to this HTML so lab-assets/ paths resolve.
  • Snapshot your lab VMs. Prefer Metasploitable 2 (acme-legacy) and DVWA (acme-shop). If VMs will not boot, use acme_mini_lab.py on 127.0.0.1.
  • Try each task yourself first. Solutions are for checking.
Ethics. Scan only your isolated lab, 127.0.0.1 mini lab, or light scans of scanme.nmap.org. Never the college, classmates, workplaces or random Internet hosts. Documentation ranges (203.0.113.0/24) are paperwork examples — not live fire.
✔ Checkpoint: ~/acme-phase2a/ contains recon-notes.md, disco or mini-lab -oA files, inventory.csv and a scope_guard transcript.

Part 0 — Brief & setup

⏱ 10 min
Goal: Confirm RoE, install or locate tools, and unzip lab assets so every path in this workbook resolves.

0.1 Unzip student assets

Download week3-lab-assets-student.zip from the LMS (or your instructor). Unzip it next to this HTML file so you have a lab-assets/ folder containing scope_guard.py, acme_mini_lab.py, nmap_to_findings.py, targets-week3.txt, passive/, templates/ and sample-output/.

Starter
unzip week3-lab-assets-student.zip
ls lab-assets

After unzipping, ls lab-assets should list those files. Paths in this lab are written as lab-assets/... relative to the folder that contains week3-lab.html.

0.2 Confirm tools

Check that nmap, python3 and dig are available on Kali (or your lab OS).

Starter
nmap --version | head -1
python3 --version
dig -v 2>&1 | head -1

Any recent Nmap 7.x is fine. Python 3.10+ is fine. If dig is missing, sudo apt install dnsutils on Debian/Kali.

2.2 Discovery scan

Prefer your host-only lab: nmap -sn -iL nmap-targets.txt --exclude 192.168.56.1 -oA ~/acme-phase2a/disco. If VMs are down, discovery-scan 127.0.0.1 after starting the mini lab (Part 3).

Starter

You should see live hosts among your Kali IP, 192.168.56.101/102 if powered on, and/or 127.0.0.1. Save the -oA trio.

Part 3 — Port & service scan

⏱ 35 min
Goal: Port-scan with service detection, save -oA, and parse XML into an inventory table.

3.1 Start the mini lab (fallback or extra target)

In a spare terminal: python3 lab-assets/acme_mini_lab.py. Leave it running. It listens only on 127.0.0.1 ports 2121, 2525 and 8080.

Starter
python3 lab-assets/acme_mini_lab.py

You should see: Acme mini lab listening on 127.0.0.1: 2121 (FTP), 2525 (SMTP), 8080 (HTTP).

Part 4 — Light NSE & service enum
